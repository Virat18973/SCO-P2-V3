# Sinter Burden Control — V30 Stable Package

Run:
`streamlit run app.py`

This package keeps the existing dashboard structure while integrating the
current v30 backend.

Includes:
- Existing dashboard layout
- Optimized burden/cost table with TOTAL
- Independent Manual Burden Control from the optimized baseline
- Dry & Wet Composition
- Editable O&M cost
- Moisture-based wet/as-received calculation
- Coke / FeO / thermal parameters
- What-if Analysis
- Bottleneck Analysis
- Reports
- Updated Master Chemistry Excel
- Strict IOL Fines = 8% and BF Returns = 17% of total non-fuel burden
